# tinyshop-api

Tiny zero-dependency Node.js shop API. It is a **sandbox** for recording
CodeBuddy Code ⇄ GitHub / GitLab automation demos (AI review, `@codebuddy`
mentions, CI auto-fix, scheduled audits, release notes).

```bash
npm test        # node:test, no dependencies
npm start       # http://localhost:3000/products
```
